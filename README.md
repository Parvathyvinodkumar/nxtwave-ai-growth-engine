# NxtWave AI Workshop Growth Engine

A referral-powered growth engine designed to drive 500 final-year engineering student registrations for a free AI workshop within 7 days.

## Problem

Final-year engineering students know AI is important but often lack practical AI projects they can showcase during placements.

## Solution

The platform turns workshop registration into a growth loop:

Landing Page
→ AI Readiness Quiz
→ Registration
→ Personalized AI Project
→ Referral Link
→ Competition
→ Leaderboard
→ More Registrations

## Key Features

- Student registration
- AI readiness assessment
- Personalized project recommendations
- Referral tracking
- Campus leaderboard
- Referral competition
- Growth milestones
- UTM attribution
- Visit tracking
- Campaign funnel analytics
- Source performance analytics
- Admin dashboard

## Growth Loop

1. Student discovers the workshop.
2. Student completes the AI readiness quiz.
3. Student registers.
4. Student receives a personalized AI project recommendation.
5. Student receives a referral link.
6. Friends register through the link.
7. Referral count increases.
8. Student moves up the leaderboard.
9. Milestones encourage further sharing.
